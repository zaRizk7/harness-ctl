# v0.2.0

Subscription monitoring can now use native account reports. OpenRouter
application programming interface (API) monitoring also shows more key spend
and budget details.

| Source | New information |
| --- | --- |
| OpenAI native account | Optional token summaries and daily token counts beside quota windows |
| Anthropic native account | Quota percentages, reset times, subscription type and available usage-credit spend |
| OpenRouter API key | Daily, weekly and monthly spend, external-provider key spend, reset policy and effective budgets |

The local refresh still defaults to five seconds. Press **F2** in the TUI for
complete information. CLI reports expose the same data. Provider fetch intervals
and delays remain separate from the local refresh.

## Configure reports

Select an installed native report source with an existing subscription sign-in.
Use `report_harness: "codex"` for OpenAI or `report_harness: "claude"` for Anthropic.
Native authentication and token refresh stay with the harness.

Existing provider configuration is preserved during upgrade. Apply the required
contracts and mappings from the
[shipped defaults](https://github.com/zaRizk7/harness-ctl/blob/v0.2.0/internal/providers/providers.json)
to your configuration. Retain your endpoint and credential choices. See the
[account guide](https://github.com/zaRizk7/harness-ctl/blob/v0.2.0/docs/accounts.md).

## Limits

Anthropic reporting uses an experimental Agent SDK (software development kit)
control interface. Native
initialization must confirm version 2.1.296 or later. Unknown runtime versions
and prereleases are rejected. Unknown inventory metadata does not block a
runtime that confirms support. Native sign-in scopes and managed policy still
apply. The shipped Anthropic fetch interval is sixty seconds.

An unsupported OpenAI token-activity method leaves valid quota data available.
Token counts and session cost estimates do not become billed API cost.
Anthropic usage credits retain their reported currency's minor units. Missing
provider fields remain unavailable. Monitoring requests no inference prompt or
local transcript scan. Live account access was not tested.

Google consumer subscription reporting remains project work. Other tracked
boundaries remain in the
[limitations guide](https://github.com/zaRizk7/harness-ctl/blob/v0.2.0/docs/limitations.md).

## Install

```sh
curl -fsSL https://github.com/zaRizk7/harness-ctl/releases/download/v0.2.0/install.sh \
  | sh -s -- --version v0.2.0
```

The bootstrap checks release checksums before setup. The macOS binaries are
unsigned and are not notarized.
