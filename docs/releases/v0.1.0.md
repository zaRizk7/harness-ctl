# v0.1.0

First public macOS binary distribution for Apple Silicon and Intel. The TUI and
CLI manage harness lifecycle operations, compatible local components, shared
library recipes and independent provider accounts. Batches use one approval and
sequential execution with encrypted local recovery. (Project, 2026)

## Native authentication

Native authentication commands run through the selected real harness executable.
Generated launchers route matching commands such as `claude auth login` through
the manager. OAuth and token refresh remain native. Opt-in encrypted profiles
capture declared native credential files and restore compatible copies after
approval. OS Keychain secrets stay native. (Project, 2026)

Explicit project/system component roots provide read-only inventory. Direct
native plugin additions are rescanned with scope provenance. Claude and Codex
marketplaces have native CLI/TUI adapters with local recovery and verification.
Local marketplace repositories retain external ownership. (Project, 2026)

## Install

```sh
curl -fsSL https://github.com/zaRizk7/harness-ctl/releases/latest/download/install.sh | sh
```

The POSIX bootstrap selects the architecture and verifies the release binary's
SHA-256 before opening setup. Use `--headless --yes` for approved unattended
setup, `--version v0.1.0` to pin the binary, and explicit prefix/direct/symlink
options for custom locations. Installation uses private user storage, requires
no administrator access and does not install Go. Checksums come from publisher
metadata over HTTPS. Signing and notarization are not configured. (Project, 2026)

## Remaining boundaries

Anthropic and Google consumer structured quota adapters remain unverified.
Native statistics interfaces and billing links are available as fallbacks.
Provider access, throttling and upstream report freshness limit monitoring.
External plugin payload mutations and unconfigured roots are outside automatic
ownership. Live vendor installations and account authentication remain untested.
See the versioned limitations before relying on those integrations. (Project, 2026)
