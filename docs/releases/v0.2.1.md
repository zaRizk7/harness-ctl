# v0.2.1

Native Anthropic subscription reports can use the existing default sign-in.
The manager previously forced `CLAUDE_CONFIG_DIR` to the default directory.
In the tested installation, that override changed native auth status from
signed in to signed out and made quota reports unavailable.

The fix preserves the inherited variable for an unconfigured, unmanaged
default Claude installation. Explicit manager roots, installation roots, named
profiles and custom catalog paths retain their selected state. Other harness
environment rules are unchanged. Native authentication and token refresh stay
with the harness.

## Verification

Local formatting, vet and the full race suite passed. Strict race-enabled
coverage passed at exactly **8,179 of 8,179 production Go statements**.
The regular suite uses synthetic homes, native processes and HTTP fixtures.

[Source CI](https://github.com/zaRizk7/harness-ctl/actions/runs/38533583668) and
[release CI](https://github.com/zaRizk7/harness-ctl/actions/runs/38533583591) passed
for the tag commit on both native macOS architectures. Both Apple Silicon
coverage gates independently reached 8,179/8,179 statements. Both release
binaries printed `harness-ctl v0.2.1`. All four draft assets match GitHub digests
and sizes. The checksum manifest is complete. The installer matches the tagged
source. Direct and symlink setup passed in disposable Apple Silicon homes.
Private modes, preserved PATH, provider defaults and absence of manager
credential/recovery files passed. Intel's public bootstrap remains untested
locally. Actual public latest and pinned downloads, headless direct/symlink
installation and interactive piped setup also passed in disposable Apple
Silicon homes. The installed bytes match the reviewed release assets.

The regression failed before the fix. Focused race tests passed after it.
User-authorized live production-adapter checks passed with existing Anthropic,
OpenAI and OpenRouter auth. They read native quota windows, optional OpenAI
token activity and OpenRouter key spend and budgets. They requested no new
sign-in, inference turn or paid plan change. They used a temporary manager root
and created no manager account vault, credential vault or recovery files.
Keys, identities and personal usage values are not part of the public evidence.

These checks cover the installed native versions and available account access.
Other versions, organization policy, lifecycle changes and service restarts
remain untested. API invoices are separate from native subscription quotas and
OpenRouter key budgets. See the
[limitations guide](https://github.com/zaRizk7/harness-ctl/blob/main/docs/limitations.md).

## Install

Use this pinned command:

```sh
curl -fsSL https://github.com/zaRizk7/harness-ctl/releases/download/v0.2.1/install.sh \
  | sh -s -- --version v0.2.1
```

The bootstrap verifies release checksums before setup. The macOS binaries are
unsigned and are not notarized. Existing provider configuration stays unchanged
during a binary upgrade.
