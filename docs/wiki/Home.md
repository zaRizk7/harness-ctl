# harness-ctl Wiki

`harness-ctl` is a macOS TUI and CLI for harness lifecycle operations, local
components, shared recipes, launch profiles and provider accounts. Operations
use concrete previews, explicit approval, ownership checks and encrypted local
recovery. Apple Silicon and Intel builds are supported. (Project, 2026)

| Tutorial | Outcome |
| --- | --- |
| [Installation](Installation) | Install a verified release or build from source, choose private setup and activate PATH |
| [Lifecycle and batches](Lifecycle-and-batches) | Install/update/remove several harnesses with one approval |
| [Components and library](Components-and-library) | Manage local entries, marketplaces and approved shared recipes |
| [Accounts and monitoring](Accounts-and-monitoring) | Add independent accounts, view usage/billing and toggle TUI details |
| [Recovery and removal](Recovery-and-removal) | Recover captured state and choose manager/harness removal independently |
| [Development](Development) | Find package ownership, run strict gates and publish reviewed docs |

Start with the [v0.1.0 release](https://github.com/zaRizk7/harness-ctl/releases/tag/v0.1.0)
or source installation.
Read the [remaining boundaries](https://github.com/zaRizk7/harness-ctl/blob/main/docs/limitations.md)
before relying on consumer quotas, project/system inventory or an unverified
vendor contract. A passing coverage gate does not establish live vendor
compatibility. (Project, 2026)
